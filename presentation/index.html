The problem

Engineers lose technical skills when they use AI tools.

  • Ford, June 2026. Ford hired 350 engineers again. The AI system did not keep the expert knowledge. Junior engineers had nobody to learn from.

The name, and the number

Cognitive debt

Cognitive debt is the difference between the system you operate and the knowledge you hold. Professor Margaret-Anne Storey defined this term.
debt(c) = frequency(c) × depth(c) × (1 − mastery(c))

frequency

How often you use the concept. We read your public repositories. We do not ask you, because people rate themselves too high.

depth

How many other concepts need this one. A weak foundation costs more than a weak detail.

1 − mastery

How little of the concept you hold. Only graded answers change this value, and each answer changes it by a small amount.
Debt is a good model for this problem. Debt grows slowly. Debt is not visible. And you can pay debt back.
Two facts. First, the term is not ours: a professor defined it. Second, we made it a number, so the program can sort concepts and select the most expensive one.
Available solutions

Every available solution removes something.

Stop the tool

Disable the AI assistant one day each week.
Cost: 20 % of the output.

Work slower

Type the generated code again by hand, line by line.
Cost: the speed you bought the tool for.

Memorise

Use flashcards and repeat them at intervals.
Cost: memory is not understanding.
These are three real products. Each one stops new debt. No product pays back the debt that already exists.
Our method does not remove the AI tool. It uses the knowledge the engineer already has.
Be fair about these three. They are honest attempts and real products. The important part is the shape they share: each one subtracts. We add.
Our method · match by role, not by name

An analogy connects two subjects by structural role.

We do not match two things because both are called "a controller". We match them because both are the single source of truth that other components compare themselves against.
etcd maps to feature store
shared role · source_of_truth
⚠ etcd is small and strongly consistent. A feature store is a view over unclean events, with an offline path and an online path. Point-in-time correctness is a new requirement that etcd never had.
liveness probe maps to drift detection
shared role · degradation_signal
⚠ A probe is cheap, binary and immediate. Labels arrive late and incomplete. Drift can look correct while the business metric fails.
The orange line is the product. An analogy without a stated limit does not pay down cognitive debt. It creates more debt, because the engineer uses the analogy after the point where it is correct.
Mapping.Breakdown is a required field in the domain model and in the plugin schema. A test checks that the agent instruction still asks for it.
Slow down here. This is the one idea nobody else in the room will state. Everybody has received a bad analogy and then used it too far. We made the limit mandatory in the type.
The question ladder

Four levels. The program selects the level, not the model.

L1
Find the match
Name the item in the new subject that has the role you already know.
L2
Find the limit ← this level does the teaching
Say where the analogy stops being correct. The system does not tell you. You must find it.
L3
Use the new terms
Answer in the vocabulary of the new subject, without the analogy.
L4
Solve a problem
Solve a small task that needs two or three new concepts together. Tests grade the result.
A deterministic function selects the concept and the level. It uses the debt value and the measured mastery. The language model only writes the text of the question. A model that selects the difficulty and grades the answer moves towards the topic it explained last.
This is the design decision to defend. The model writes sentences. The model does not decide if you passed, and it does not decide what comes next. That part is code, and it is testable.

role · quota of allowed states
⚠ You can increase a rate limit, because a rate limit is a policy. You cannot increase entropy, because entropy counts the states the system can occupy.

role · value from earlier values
⚠ A window function runs in one pass. A recurrence can branch, and it can compute the same state again until you add memoisation.

The application runs on your computer

This is a proof of concept, so we did not build accounts or sessions. Your profile, your mastery and your analogies are one SQLite file on your disk.
There is also a second reason. A list of the subjects you do not know is private information.
